# SENTINEL n8n Cloud workflows

Two importable workflows:

- `sentinel-run-complete.json` — receives the run-complete webhook, appends a
  row to Google Sheets, sends a Telegram score summary, creates a Trello card
  when `score_after < 5`, and returns `200`.
- `telegram-test-trigger.json` — listens for a Telegram `/test` command, calls
  the Sentinel API at `https://YOUR_SENTINEL_API_URL/v1/runs`, and sends the
  measured score and `run_id` back to Telegram.

No credentials or real IDs are embedded. Replace the placeholders in the n8n
Cloud UI.

## n8n Cloud setup

1. Create a free n8n Cloud account at <https://n8n.io/cloud/>.
2. Open your Cloud workspace.
3. Go to **Workflows**.
4. Open the **⋯** menu and choose **Import from File**.
5. Import `workflows/n8n/sentinel-run-complete.json`.
6. Repeat **Import from File** for
   `workflows/n8n/telegram-test-trigger.json`.
7. Open **SENTINEL — Run Complete** and activate it with the **Active** toggle.
8. Copy the Cloud production webhook URL. It looks like:

   ```text
   https://<name>.app.n8n.cloud/webhook/sentinel-run-complete
   ```

9. Set that URL as `N8N_WEBHOOK_URL` in the Sentinel API environment (local
   `.env` or deployment secret) and restart the API.

> n8n Cloud is a paid product after its free trial. The SENTINEL demo does not
> require n8n at all. With `N8N_WEBHOOK_URL` unset, the run completes normally
> with `N8N_STATUS=skipped`.

## Credentials to connect in the n8n Cloud UI

### Google Sheets OAuth2 API

Create a credential of type **Google Sheets OAuth2 API** and fill:

- **Client ID**
- **Client Secret**
- **OAuth Redirect URL** — copy the URL n8n Cloud displays into the Google
  Cloud OAuth client.
- Click **Sign in with Google** and complete consent.

Open **Append run to Google Sheets** and select that credential.

Prepare a spreadsheet with the header row:

```text
run_id | score_before_label | score_after_label | failure_ids | patch_ids | created_at
```

Set the node's **Document** to the spreadsheet and **Sheet Name** to `Sheet1`
(or change the node to the tab you use).

### Telegram API

Create a credential of type **Telegram API** and fill:

- **Access Token** — the bot token from BotFather.

Connect this credential to **Send Telegram message** in the run-complete
workflow. Connect the same credential to **Telegram Trigger** and
**Send score to Telegram** in the `/test` workflow. Replace
`YOUR_TELEGRAM_CHAT_ID` with the destination chat ID.

### Trello API

Create a credential of type **Trello API** and fill:

- **API Key**
- **API Token**

Connect it to **Create Trello card**. Replace `YOUR_TRELLO_LIST_ID` with the
target Trello list ID.

## Telegram `/test` workflow

Replace `https://YOUR_SENTINEL_API_URL/v1/runs` in the **Run Sentinel** HTTP
Request node with the public URL of the Sentinel API. n8n Cloud cannot call a
local machine directly. Activate the workflow after connecting the Telegram
credential.

## Webhook payload

`graph.py` posts this shape:

```json
{
  "event": "sentinel.run.completed",
  "run_id": "00000000-0000-0000-0000-000000000000",
  "score_before": 1,
  "score_before_label": "1/5 (20%)",
  "score_after": 5,
  "score_after_label": "5/5 (100%)",
  "target_version_before": "v1",
  "target_version_after": "v2",
  "failure_ids": ["S2", "S3", "S4", "S5", "S6", "S7", "S8", "S9", "S10", "S11", "S12"],
  "patch_ids": ["S2", "S3", "S4", "S5", "S6", "S7", "S8", "S9", "S10", "S11", "S12"]
}
```

`created_at` for the spreadsheet is generated by n8n with `$now.toISO()`
because the webhook payload does not contain it.

Test the Cloud webhook:

```bash
curl -X POST https://<name>.app.n8n.cloud/webhook/sentinel-run-complete \
  -H "Content-Type: application/json" \
  -d '{
    "event": "sentinel.run.completed",
    "run_id": "00000000-0000-0000-0000-000000000000",
    "score_before": 1,
    "score_before_label": "1/5 (20%)",
    "score_after": 5,
    "score_after_label": "5/5 (100%)",
    "target_version_before": "v1",
    "target_version_after": "v2",
    "failure_ids": ["S2", "S3", "S4", "S5", "S6", "S7", "S8", "S9", "S10", "S11", "S12"],
    "patch_ids": ["S2", "S3", "S4", "S5", "S6", "S7", "S8", "S9", "S10", "S11", "S12"]
  }'
```

Without Google Sheets, Telegram, or Trello credentials, those nodes fail. The
webhook still receives the payload and returns 200; live delivery is **not**
verified until the credentials above are connected.

## IF branch

The **IF score_after < 5** node reads
`{{ $('Webhook').item.json.body.score_after }}` and compares it to `5`. It does
not use a hard-coded score. Trello runs only on the true branch; the false
branch goes directly to **Respond 200**.
